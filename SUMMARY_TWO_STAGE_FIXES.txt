FIX #1: Learning Rate ⬇️ 10x Reduction
---------------------------------------
BEFORE: stage2_lr: 0.0001 (1/100 of base_lr)
AFTER:  stage2_lr: 0.00001 (1/1000 of base_lr)

WHY: Ultra-low LR prevents catastrophic forgetting of Stage 1 features.

FILE: cfgs/psnet12/respointnet2_two_stage_FIXED.yaml, line 69

FIX #2: Warmup Disabled 🚫
---------------------------
BEFORE: stage2_warmup_epochs: 10 (ramps up to full LR)
AFTER:  stage2_warmup_epochs: 0 (disabled)

WHY: With ultra-low LR, warmup is unnecessary and harmful. Model can adapt
     immediately without risk of forgetting.

FILE: cfgs/psnet12/respointnet2_two_stage_FIXED.yaml, line 70
CODE: LTL/two_stage_trainer.py, _train_epoch_stage2()
      Auto-disables if stage2_lr <= 0.00002


FIX #3: CE Loss Instead of CB Loss ✂️
--------------------------------------
BEFORE: use_cb_loss_stage2: true (CB loss + CB sampler)
AFTER:  use_cb_loss_stage2: false (CE loss + CB sampler)

WHY: Class-balanced sampler handles imbalance. CB loss is redundant and
     creates unstable gradients.

FILE: cfgs/psnet12/respointnet2_two_stage_FIXED.yaml, line 73


FIX #4: Strong Regularization 💪
---------------------------------
BEFORE: stage2_weight_decay: 0.001 (same as Stage 1)

NEW VERIFICATION SYSTEM
================================================================================

Created comprehensive verification functions in LTL/training_verifier.py:

1. verify_encoder_frozen()
   - Checks encoder parameters are frozen
   - Detects any trainable encoder layers
   - Raises error if leakage found

2. verify_no_gradient_leakage()
   - Checks gradients after backward pass
   - Ensures frozen params don't receive gradients
   - Raises error if leakage detected

3. verify_class_balanced_sampling()
   - Samples batches to check distribution
   - Calculates balance ratio (max/min)
   - Logs per-class statistics

4. verify_stage2_not_degrading()
   - Monitors mIoU vs Stage 1 baseline
   - Warns if drop > 5%
   - Errors if drop > 10%

5. run_all_verifications()
   - Runs all checks at once
   - Recommended at start of Stage 2

TROUBLESHOOTING
================================================================================

Issue: "No improvement over baseline"
  → Expected! Check if degradation < 1%
  → Try: Reduce LR to 0.000005 or increase epochs to 50

Issue: "Performance degrading"
  → Reduce LR by 50% (0.00001 → 0.000005)
  → Increase regularization (weight_decay: 0.01 → 0.02)
  → Check verification logs for leakage

Issue: "CUDA out of memory"
  → Reduce batch_size: 6 → 4 → 3
  → Reduce num_points: 15000 → 12000

Issue: "Class distribution severely imbalanced"
  → Increase sampling_temperature: 2.0 → 3.0
  → Check if class-balanced sampler is enabled
  → Review sampler logs

Issue: "Encoder leakage detected"
  → CRITICAL BUG! Stop training immediately
  → Verify freeze_encoder: true in config
  → Check model architecture
